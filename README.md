# BodEconomy — Bodegón Control ERP

Sistema integral de gestión de caja, control de gastos, arqueo diario y auditoría financiera para El Bodegón Restaurante & Bar.

## Características
- **Caja General**: Arqueo y conciliación de ventas (Efectivo y Dólares con tipo de cambio dinámico).
- **Caja Chica**: Libro Diario de egresos con control estricto de gaveta física vs. transferencias y tarjetas.
- **Sincronización Cloud**: Integración continua con Supabase y panel web Bodepass.
- **Auditoría & Reportes**: Impresión térmica de tirillas y actas contables en PDF/Excel.
- **Auto-Actualizaciones**: Despliegue automático en computadoras cliente mediante GitHub Releases y `electron-updater`.
